Step 4 of 7

Fetch your articles
Use a GET request to list your articles. This returns summaries — no full content yet.
Guide
Copy for agent
LIST ALL ARTICLES
Copy
curl -X GET \
  "https://api.babylovegrowth.ai/api/integrations/v1/articles" \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json"
GET ONE ARTICLE (FULL CONTENT)
Copy
curl -X GET \
  "...v1/articles/12345" \
  -H "X-API-Key: your_api_key" \
  -H "Content-Type: application/json"
Replace 12345 with the article id from the list response to get full content_html and content_markdown.

Step 5 of 7

Paginate large results
Control how many articles you fetch at once using limit and offset.
Guide
Copy for agent
PAGINATION PARAMETERS
Copy
# First 50 articles
...v1/articles?limit=50&offset=0

# Next 50 (page 2)
...v1/articles?limit=50&offset=50

# Max per call: 500
Articles are sorted newest first. If a response returns fewer articles than your limit, you've reached the end.
Store it yourself — don't fetch on demand
The API is rate-limited, so don't call it on every page view. Sync all articles into your own storage (files or a database) and serve them from there.
Publish new articles automatically: run the sync on a schedule — a cron job, a scheduled CI workflow (e.g. GitHub Actions), your framework's build hook / ISR, or a background job — so new content appears without manual work.
